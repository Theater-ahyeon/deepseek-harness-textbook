# 阅读版排版调整

排版参考：[《深入理解 AI Agent》](https://bojieli.github.io/ai-agent-book/)。实际查看首页和第一章：白底顶栏、左侧全书目录、中间正文、右侧小节目录，以及首页的章节速览。阅读版采用相同的信息布局，样式与交互在本地独立实现。

## 阅读方式

- 打开 `reader.html`，首页展示十九章的学习目标卡片。
- 点击左侧章节，按章阅读；正文下方可进入上一章或下一章。
- 点击“全文阅读”，连续浏览十九章；点击“按章阅读”恢复章节视图。
- 点击顶部搜索按钮或按 `/`，搜索十九章的标题和正文；选择结果直接进入对应章节。搜索补充页面时，结果来自该页面。
- 右侧目录定位当前章节的小节，并标出当前阅读位置。
- 勾选“隐藏源码研读”先读机制说明；进入源码搜索结果时自动显示相关内容。
- 手机上通过左上角打开全书目录，通过“本页目录”打开小节列表。宽图和表格在各自区域内横向滚动。

## 内容与构建

十九章、补充能力与基础附录的 Markdown 正文逐文件核对 SHA-256。正文、技术结论、原码节选和专有名词保持本轮审校后的内容。六个 HTML 阅读页面统一使用新排版。

维护模板位于本地 `_tools/reader-layout.html`、`_tools/reader-layout.css` 和 `_tools/reader-layout.js`。构建时内嵌样式和脚本，阅读端不需要联网。运行 `_tools/build_course.py --package` 同步阅读页面与分享包。

## 核验记录

在实际 Edge 中检查桌面与手机视口、十九章切换、搜索、源码显示、小节定位和补充页面；保存截图并人工查看。核验结果与阅读文件哈希绑定，记录在 `validation.json` 的 `browser_review` 中。ZIP 核验 CRC 并逐文件比较内容。
